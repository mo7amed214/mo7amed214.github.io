Thesis

Feb – Jun 2026

Modeling Purdue Level 3 for an Industrial Honeypot

Bachelor thesis, German University in Cairo. Supervised by Dr. Amr Mohamed Saber.

A honeypot of the operations layer of a discrete-manufacturing plant, built as one layer of a seven-person project. My part was the engineering workstation, a process historian, and an OPC UA server in C (open62541) fed by a simulator in which tags actually affect each other, so the plant behaves like a plant instead of a random-number generator.

  • An eight-step attack chain I implemented and validated: credentials in an anonymous SMB share, SSH, Nmap reconnaissance, historian and OPC UA access, ARP man-in-the-middle, then tag manipulation with asyncua. A quieter variant writes plausible values instead of obvious spikes.
  • Deception chosen from MITRE ATT&CK for ICS, including a decoy OPC UA endpoint planted in the documentation. It measurably slowed down an autonomous LLM agent attacking the environment.
  • Detection with Sysmon, Zeek scripts, 26 custom Wazuh rules and Grafana dashboards for OT telemetry and SOC triage.
  • A bidirectional LSTM with attention that classifies attacker sessions by danger level, attack path and intent: 94.7% danger-level accuracy on 660 held-out examples.
